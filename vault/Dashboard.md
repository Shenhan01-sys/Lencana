# 📊 Dashboard

Dynamic overview. Every list below is **generated by Dataview** — add a note and it appears, no
manual index to keep in sync. Needs the Dataview plugin (bundled locally, not committed:
`.obsidian/` is in `../.gitignore`, see [[Conventions]]).

## 📁 Every note, by folder and date

```dataview
TABLE WITHOUT id
  file.folder AS "Folder",
  status AS "Status",
  file.mtime AS "Edited"
FROM ""
WHERE file.name != "Dashboard" AND file.name != "_Auto-Index"
SORT file.folder ASC, file.name ASC
```

## 🧪 Harness records (the home of measured numbers)

```dataview
TABLE WITHOUT id
  file.link AS "Record",
  command AS "Command",
  date AS "Measured",
  result AS "Result"
FROM #testing
SORT file.name ASC
```

## 📌 Open items, by status

```dataview
TABLE WITHOUT id
  file.link AS "Item",
  owner AS "Owner",
  severity AS "Severity",
  raised AS "Raised"
FROM #open-item
SORT file.name ASC
```

## ✅ Acceptance criteria per backlog item

```dataview
LIST
FROM #acceptance
SORT file.name ASC
```

## 🧾 Executive summaries (one per finished item)

```dataview
TABLE WITHOUT id
  file.link AS "Item",
  status AS "Status",
  file.mtime AS "Written"
FROM #exec-summary
SORT file.name ASC
```

## 🧩 Concepts and decisions

```dataview
LIST
FROM #concept OR #decision
SORT file.name ASC
```

## 🗝️ Recent notes (what changed lately)

```dataview
TABLE WITHOUT id file.folder AS "Folder", file.mtime AS "Edited"
FROM ""
SORT file.mtime DESC
LIMIT 12
```

## 🏷️ Tag census

```dataview
TABLE WITHOUT id
  length(rows) AS "Notes",
  rows.file.link AS "Which"
FROM ""
FLATTEN file.tags AS tag
GROUP BY tag
SORT length(rows) DESC
LIMIT 30
```

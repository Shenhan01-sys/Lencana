# 02 - Problem

**Hub:** [[13-SubmissionDocs/Slides/00 - Konsep dan Gaya Deck]] · **Sebelumnya:** [[13-SubmissionDocs/Slides/01 - Cover]] · **Berikutnya:** [[13-SubmissionDocs/Slides/03 - The Proof Layer]]

**Tujuan:** juri langsung "ngeh" masalahnya — tiga lubang, masing-masing jadi benda, bukan paragraf.

## Di layar (teks persis)

- Judul: **A certificate is *just a file*.**
- Tiga adegan berjajar kiri → kanan, label pendek di bawah masing-masing:
  1. **Anyone can edit it** — stiker amber `NEW NAME` · `HIGHER SCORE`
  2. **The fake looks real** — label `Which one is edited?`
  3. **Checking means asking the issuer… and waiting** — label `no reply yet`
- Pita bukti di bawah (mono kecil, abu):
  `We read six open-source learning platforms at pinned commits — Moodle, Open edX, Canvas, Chamilo, Frappe LMS, LearnHouse.`
  `In none of them can a stranger tell whether a credential is still valid without asking the platform that issued it.`
  `Moodle's badge exporter: "Signed is not implemented yet."`

## Visual (benda inti)

Ilustrasi datar (§2 hub), tiga adegan di satu garis dasar:

1. **Sertifikat generik** krem datar (`#f3eee2`: bilah judul, bilah nama, angka nilai, medali kecil — jelas bukan desain
   Lencana) dengan **popover edit gaya FE** di sampingnya: kolom input `#1e2329` bertepi `#3a414c`, caret emas, panah
   kursor datar putih. Stiker jingga `NEW NAME` · `HIGHER SCORE` menempel miring.
2. **Tiga sertifikat datar identik dikocok** seperti permainan gelas; chip `?` emas di atas masing-masing; ikon kaca
   pembesar (lingkaran + gagang, garis 4 px) menyapu dan tidak menemukan beda.
3. **Dua simpul ikon**: *Hiring team* (ikon orang) → *The issuer* (ikon gedung), disambung garis putus-putus `#3a414c`;
   ikon amplop berjalan di garis; jam datar di bawahnya, jarumnya berputar cepat dan chip hari berganti
   `Mon → Tue → Wed …`; chip abu `no reply yet`.

## Gerak

- **Masuk:** tiga adegan muncul berurutan (stagger 200 ms), masing-masing dengan micro-beat-nya: nama dihapus lalu
  diketik ulang → kocok → amplop berangkat.
- **Terus:** caret mengetik ulang, sertifikat terus dikocok pelan, jarum jam tidak berhenti.
- **Penutup slide (opsional):** blok merah datar penuh **JUST TRUST IT?** 0,7 dtk, lalu sertifikat **pecah jadi
  poligon datar** → slide 03.

## Catatan pembicara (±25 dtk)

> Today a certificate is just a file. Anyone can change the name or the grade in seconds, and the fake looks exactly
> like the real one. To check it, a recruiter has to ask the issuer — and wait. We read the code of six open-source
> learning platforms: in none of them can a stranger tell if a credential is still valid without asking the platform.
> Moodle's own exporter says it: "Signed is not implemented yet." So most people just trust it.
